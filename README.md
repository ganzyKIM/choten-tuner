# 초텐 튜너 (Choten Tuner)

도스/Win95 감성 레트로 테마의 안드로이드 조율기 앱.
초텐짱 프로젝트(choten-translate)의 디자인 언어와 캐릭터를 그대로 이어받았다.

## 기능

- **튜너** — 마이크로 들은 소리에서 가장 가까운 음이름과 센트 편차를 가로 미터로 표시한다.
  중앙이 정확, 왼쪽이 낮음(♭), 오른쪽이 높음(♯). YIN 피치 검출에 포물선 보간과 미디언 스무딩을 얹었다.
- **악기 프리셋** — 범용 / 기타 / 베이스 / 바이올린 / 해금 / 샤미센 / 피아노.
  악기 음역 밖의 잡음과 옥타브 오검출을 걸러낸다.
- **마이크 보정** — 측정이 일정하게 높거나 낮게 나오는 환경에서 그 차이를 센트 단위로 상쇄한다.
  정확한 음을 들려주면서 버튼 한 번으로 자동 보정할 수 있다.
- **마이크 민감도** — 무음으로 취급할 RMS 게이트를 1~10단계로 조절한다. 숫자가 클수록 작은 소리까지 잡는다.
  설정 화면에 실시간 입력 레벨 바와 감지 기준선이 같이 나와서 감으로 고르지 않아도 된다.
- **소리내기** — 옥타브 2~6의 12음 중 하나를 골라 기준음을 계속 재생한다.
  클릭 없는 사인파, 음 전환은 포르타멘토.
- **변신** — 라이트(초텐짱) ↔ 다크(아메) 테마 전환. 팔레트·캐릭터·말투가 통째로 바뀌고 설정은 저장된다.
- **마스코트** — 화면 아래 캐릭터가 상황에 맞는 표정으로 바뀌고 도스식 타자기 효과 대사창으로 말을 건다.
  터치하거나 변신할 때 별이 흩어졌다 사라진다.
- **설정** — A4 기준 주파수(435~445Hz), 악기 프리셋, 마이크 보정(±30센트), 마이크 민감도.

### 표정 매핑

| 상황 | Sprite | 초텐짱 | 아메 |
|---|---|---|---|
| 튜닝 중 / 완전음정(C·F·G) | NEUTRAL | default | default |
| 장음정(D·E·A·B) | JOY | peace | dere |
| 마이크 권한 없음 | SHARP | angry | yandere |
| 대기(무음) | FLAT | vape | smoking |
| 단음정·트라이톤(C#·D#·F#·G#·A#) | DARK | vape | drug |

소리가 들어오는 동안에는 표정과 대사가 하나로 고정된다. 편차는 미터가 실시간으로 보여주고,
캐릭터는 조율에 방해되지 않게 가만히 있는다. 음색 분류는 C 기준 음정으로 판단한다 —
완전음정은 평음, 장음정은 밝음, 단음정과 트라이톤은 어두움. 상태 전환에는 400ms 안정화 지연이 걸려
경계값에서 깜빡이지 않는다.

캐릭터를 터치하면 폼별로 11~12가지 포즈·대사 세트 중 하나가 나온다. 직전과 다른 포즈를 강제로 골라서
연속으로 눌러도 매번 다르게 보인다.

## 스택

- Kotlin + Jetpack Compose. Material 컴포넌트 없이 커스텀 레트로 위젯으로 짰다
- minSdk 24 / targetSdk 34, AGP 8.5.2, Gradle 8.7
- 오디오: `AudioRecord`(44.1kHz 모노) / `AudioTrack`(스트리밍 사인파)
- 피치 검출: YIN (de Cheveigné & Kawahara, 2002) 자체 구현
- 폰트: [Galmuri](https://github.com/quiple/galmuri) (SIL OFL 1.1)

## 빌드

```
gradlew.bat :app:assembleDebug
```

APK 는 `app/build/outputs/apk/debug/app-debug.apk`.

보안 프로그램이 SSL 검사를 하는 환경에서는 의존성 다운로드가 막힌다.
`gradle.properties` 에 `-Djavax.net.ssl.trustStoreType=WINDOWS-ROOT` 를 넣어 뒀다.

## 테스트

```
gradlew.bat :app:testDebugUnitTest
```

DSP 코어(음정 수학, YIN 검출기)는 합성 파형 기반 JVM 유닛테스트로 검증한다.
`YinAccuracyTest` 는 C2~E6 전 구간의 검출 오차를 센트 단위로 재고 1센트를 넘으면 실패한다.
현재 최악값은 C6에서 +0.47센트고 나머지 구간은 0.05센트 미만이다.
즉 실사용에서 몇 센트씩 어긋나 보이면 원인은 알고리즘이 아니라 마이크·스피커·실내 음향이며,
마이크 보정으로 상쇄하면 된다.
